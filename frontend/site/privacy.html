Privacy Policy & Data Architecture

Effective Date: October 19, 2026 • Version 1.0.0

1. Our Core Principle: Your Data Belongs to You

DataVerse was built from the ground up for organizations with strict compliance, confidentiality, and data sovereignty requirements. We believe that asking questions of your data should never force you to compromise proprietary records or customer information.

2. Windows Desktop Application: 100% Air-Gapped

Zero Network Transmission: The desktop installer (DataVerse_Setup_v1.0.exe) operates in complete isolation.
  • Local Execution: The Python application, SQLite database engine, natural language parser, and WebView2 desktop window execute entirely within local process memory on your workstation.
  • Zero Telemetry: The desktop binary contains no tracking beacons, phone-home mechanisms, or automated update pings.
  • Offline Operation: You can pull your network cable or disable Wi-Fi and DataVerse continues to function with 100% feature parity.

3. Cloud Web Studio: Ephemeral Session Sandboxes

For visitors using the hosted web studio (https://dataverse-studio.netlify.app):

  • Isolated Temporary Databases: Uploaded CSV or SQLite files are stored in temporary files tied strictly to an ephemeral session identifier.
  • No Long-Term Retention: We do not log, persist, or back up uploaded database rows. When your session terminates or times out, temporary database files are automatically purged from the host container.
  • Encrypted in Transit: All communications between the browser client and the backend API are encrypted using modern Transport Layer Security (TLS 1.3 / HTTPS).

4. Zero-Bypass Security & Read-Only Invariants

To prevent accidental deletion or corruption of underlying data sources, generated SQL queries pass through mandatory abstract syntax tree (AST) verification and SQLite's native C-level set_authorizer hook. Any instruction attempting DROP, DELETE, UPDATE, INSERT, ALTER, or external file attachment is blocked unconditionally before bytecode compilation.

5. Contact & Support Inquiries (Formspree)

When you submit a message through our support portal (support.html), the information you provide (name, email address, category, subject, and message text) is transmitted securely via Formspree (Form endpoint: xzedwwlv). This data is utilized solely by the project maintainers to evaluate your inquiry and provide assistance. We do not sell, rent, or distribute your email address to third-party marketing brokers.

6. Website Analytics (Google Analytics 4)

The public product website utilizes Google Analytics 4 (Measurement ID: G-H7BHJ4W523) to assess aggregate visitor traffic, documentation engagement, and download click counts.

  • IP Anonymization: IP addresses are anonymized automatically by default in Google Analytics 4.
  • No Data Content Tracked: We strictly prohibit tracking personal identification, database cell contents, table contents, or confidential query values.
  • Opt-Out: You may disable cookies or use browser privacy extensions (e.g. uBlock Origin) without impacting your ability to browse the site or use the software.

7. Open Source Licensing & Auditing

DataVerse is open source software licensed under the permissive MIT License. You are encouraged to inspect our complete codebase, security filters, and authorizer implementations on our public GitHub repository: github.com/shaik-irfan-basha/DataVerse.
