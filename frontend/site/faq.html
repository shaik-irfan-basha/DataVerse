Security & Data Privacy

Is my database content or uploaded data sent to external cloud servers?

Desktop Edition: Absolutely not. In the Windows Desktop edition, 100% of the runtime (Python interpreter, SQLite database engine, WebView2 interface, and query execution) executes locally inside your machine's memory. Zero network requests leave your computer.

Cloud Web Studio: Datasets uploaded to the web studio are written to ephemeral in-memory or temporary files on Render. They are strictly segregated by session ID and are completely destroyed once your session ends or times out.

How does Zero-Bypass SQL Security prevent accidental data destruction?

DataVerse implements defense-in-depth across two separate layers:

  1. AST Validation (SQLGlot): Every generated statement is parsed into an abstract syntax tree. If any non-SELECT node (such as DROP, DELETE, INSERT, UPDATE, ALTER) is found, the query is rejected before execution.
  2. C-Level SQLite Authorizer: At the native driver level, SQLite's C API hook sqlite3_set_authorizer explicitly forbids any write action codes, table attachments, or PRAGMA changes. Even if an attacker constructed an AST-bypassing payload, the database engine itself terminates execution.
Can I run DataVerse in an enterprise air-gapped environment?
Yes. The Windows desktop installer (DataVerse_Setup_v1.0.exe) is completely self-contained. It contains all bundled wheels, Python binaries, and assets. You can install it on secure network segments without internet access.

Installation & Windows SmartScreen

Why does Windows Defender SmartScreen show "Windows protected your PC"?

Microsoft Defender SmartScreen assigns trust based on cryptographic reputation and code-signing certificates. As an independent open-source release without an expensive corporate Extended Validation (EV) certificate, newly published binaries trigger this standard informational prompt.

To proceed safely: Click "More info" → click "Run anyway". You can verify the integrity of your download by verifying our published SHA-256 hash.

How can I verify the installer's SHA-256 checksum?
Open Windows PowerShell in the folder where you downloaded the file and run: 
Get-FileHash -Algorithm SHA256 .\DataVerse_Setup_v1.0.exe
The hash must match: 61B41EA7B62CDBBDF1E70839D93A57D316175984888BBED710BF106858A5BBC7

Supported Formats & Performance

What file types and databases can DataVerse ingest?
DataVerse natively accepts CSV (delimited), TSV, Excel workbooks (.xlsx / .xls), and SQLite databases (.sqlite / .db). Multiple files can be ingested simultaneously to construct relational topologies. Direct PostgreSQL and DuckDB live connections are planned for v1.1.0.
What is the 82.9% Semantic Benchmark score?
DataVerse was evaluated across a standardized 55-case natural-language SQL benchmark suite (recorded in benchmark_20261014_180323.json) tested on Groq (openai/gpt-oss-20b). It achieved an 82.9% semantic execution accuracy (29/35 matching result rows exactly), a 94.3% SQL execution success rate (33/35 queries running without SQLite errors), an 80.0% ambiguity clarification true positive rate, and a 1.42s median turnaround time with 100% adherence to read-only safety invariants.
