DataVerse Documentation

          v1.0
        

        

          
            Open Swagger UI ↗
          
          
        

      


      

        

          

            
            1. Natural Language SQL Lab
          

          

            Type questions in natural human language (e.g. "Show top 5 customers by sales in California"). DataVerse analyzes your loaded tables and schema, constructs grounded prompts, generates verified SQLite SQL via your configured AI model, and executes the query with zero-bypass multi-stage security validation.
          

          
SELECT state, COUNT(*) as customer_count FROM customers GROUP BY state ORDER BY customer_count DESC LIMIT 5;

        


        

          

            
            2. Schema Studio & Relational ER Diagrams
          

          

            Visualizes foreign keys, primary keys, and inferred relational bridges between tables on an interactive canvas. Use the canvas controls to pan, zoom, auto-arrange nodes, or construct multi-table JOINs using the Join Builder in the right-hand Inspector.
          

        


        

          

            
            3. Conversational Clarification Engine
          

          

            When ambiguous terms like "best-performing", "active", or "top tier" are detected, DataVerse asks proactive clarification questions. Clarifications can be answered with quick suggestion chips or custom responses to steer SQL generation.
          

        


        

          

            
            4. Bring Your Own Key (BYOK) & Privacy
          

          

            DataVerse operates with zero central cloud logging of your datasets. Your data files and in-memory SQLite tables never leave your local machine. API keys configured in Settings are encrypted in SQLite WAL metadata and utilized solely for schema-grounded SQL translation.
