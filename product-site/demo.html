Curated Test Cases & Starter Prompts

When you enter the studio, click "Load Sample Data" (or upload sample_sales.csv) and try running these queries to test DataVerse's unique multi-tiered intelligence:

Aggregations & Charts Test 01

"What are total sales by region?"

Tests single-table grouping, SUM aggregations, and automatic publication-grade bar chart generation.

Generated SQL:
SELECT region, SUM(sales) AS total_sales
FROM sales_data GROUP BY region;
Ambiguity Clarification Test 02

"Show me the good products."

Tests the Clarification Engine. The system refuses to hallucinate what "good" means, instead presenting schema-grounded choices (highest sales vs. lowest sales vs. sales ranking).

Clarification Prompt:
• Products with highest sales
• Products ranked by total sales
Relational JOINs Test 03

"Top 5 customers by total order spend"

When multi-table databases are connected, DataVerse automatically resolves primary/foreign keys to generate clean INNER JOINs with descending LIMITs.

Generated SQL:
SELECT c.name, SUM(o.amount) FROM customers c
JOIN orders o ON c.id = o.customer_id
GROUP BY c.id ORDER BY 2 DESC LIMIT 5;
Conversational Cleaning Test 04

"Fill missing region with 'Unknown' and trim whitespace"

Switch to the Cleaning tab to run natural language data repairs. Review before/after diffs in real time with single-click undo.

Clean Execution:
• 4 missing cells populated with "Unknown"
• 12 whitespace anomalies trimmed

Interactive Demo Sandbox & Security Invariants

Zero-Bypass C-Authorizer

The backend employs SQLite's native C authorizer hook at the driver layer. Any attempt to run DDL, DML, or attach files is blocked before bytecode execution.

Ephemeral Session Isolation

Each session receives an isolated in-memory/temp database. Data uploaded in the web demo is strictly bound to your browser session and purged when closed.

Clickjacking Protection

DataVerse enforces strict X-Frame-Options: DENY and X-Content-Type-Options: nosniff security headers, safeguarding your session from frame embedding.
