Quickstart

1. Getting Started in 3 Minutes

Whether you use the web studio or the Windows desktop application, the fundamental lifecycle consists of three steps:

  1. Ingest your data: Drag-and-drop a CSV file, an Excel workbook (.xlsx), or a SQLite database (.db / .sqlite). You can also click "Load Sample Data" to evaluate immediately.
  2. Inspect the schema: Review detected columns, sample records, and inferred relationships in the Schema panel.
  3. Ask a question: Type your question in plain English in the query input and press Enter.
Storage & Parsing

2. Data Ingestion Formats & Limits

DataVerse includes native streaming loaders that sanitize column identifiers, detect date/numeric types, and index primary keys automatically:

  • CSV / TSV (Comma / Tab Separated): Automatically detects delimiters, header rows, and null string representations (NA, null, -).
  • Excel (.xlsx, .xls): Extracts individual worksheets and creates discrete relational tables for each sheet.
  • SQLite Database Files: Preserves existing schema constraints, composite indexes, and foreign key definitions.
Scale Recommendation: The desktop edition comfortably processes datasets up to 1,000,000 rows locally. In the cloud web studio, sessions are capped at 50 MB uploads to ensure fast browser response times.
Query Formulation

3. Natural Language Querying Tips

The Natural Language Engine understands synonyms, relative dates, aggregations, and business metrics without needing strict SQL terminology:

Aggregations & Summaries
"What is the average transaction amount for each payment method in Q3?"
Generates AVG(amount) grouped by payment method with date interval filtering.
Multi-Table Joins
"List the top 10 customers by total spend who registered after January 2024"
Automatically joins customers with orders on primary/foreign key pairs.
Ambiguity Resolution

4. Proactive Ambiguity Clarification

When a query contains subjective adjectives without measurable criteria (e.g. "good products", "valuable accounts", "slow orders"), DataVerse does not guess. It computes an ambiguity score and presents schema-grounded interpretations:

Ambiguity Card Displayed:
"Good products" does not specify a quantifiable metric. Please select your intended goal:

Clicking an option immediately binds that interpretation to the query pipeline, executing the exact SQL matching your decision without starting over.

Data Preparation

5. Conversational Cleaning Studio

Dirty data causes inaccurate SQL aggregations. Switch to the Cleaning Studio tab to perform live transformations using plain English:

  • "Trim whitespace in customer names and title-case them"
  • "Fill empty country codes with 'US'"
  • "Remove duplicate records based on email and phone"
  • "Parse dates in 'order_date' column to standard ISO YYYY-MM-DD"

Every transformation generates an interactive side-by-side diff. You can review the exact affected rows before accepting, and click Undo at any time to revert immediately.

Relational Modeling

6. Interactive ER Canvas & Schemas

DataVerse reconstructs relational graphs dynamically upon ingestion. On the Schema Canvas tab, you can:

  • Inspect tables as interactive cards displaying column names and inferred SQLite data types.
  • Trace connecting foreign-key lines showing parent-child relationships and join cardinalities.
  • Click any column to see value distribution hints and null percentages.
Quality & Diagnostics

7. Profiling & Anomaly Diagnostics

The Data Profiler audits your active dataset for structural defects:

  • Null Rate Alerts: Columns with > 15% missing data are flagged with warning badges.
  • Cardinality Metrics: Identifies potential primary key candidates (100% uniqueness).
  • Type Drift Warnings: Detects numeric columns contaminated with string values (e.g. "N/A").
Support & Fixes

8. Troubleshooting & Known Issues

Port 8000 already in use (Desktop Edition)

DataVerse automatically searches for an available alternate port (8001, 8002...) if 8000 is occupied by another local service. Check the desktop console log for the active assigned port.

Microsoft Edge WebView2 Missing

Windows 10 and 11 usually have the Evergreen WebView2 runtime installed by default. If your Windows edition does not have it, download the free official WebView2 runtime from Microsoft's website.

Query Timeout on Massive Databases

To protect application responsiveness, queries that exceed 15 seconds are halted automatically. Ensure the target columns in your join or filter clauses are indexed for peak performance.
