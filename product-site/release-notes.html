What's New in v1.0.0

Zero-Bypass Dual-Tier SQL Security

Engineered two independent security layers: SQLGlot AST validation enforcing 12 AST safety rules, and native C-level sqlite3_set_authorizer hooks blocking any DDL, DML, or PRAGMA commands at the database driver layer. 100% read-only invariant verified across test suites.

Clarification Engine for Subjective Queries

Queries with ambiguous or ungrounded phrasing (such as "Show me the good products") no longer trigger random guesses. The Clarification Engine calculates semantic confidence and surfaces schema-grounded choices before execution.

Self-Healing SQL Error Recovery

Introduced an iterative 2-pass feedback loop. When SQLite throws syntax or schema exceptions, the engine captures the exact SQLite error message and schema definitions to re-generate an accurate statement automatically.

Conversational Data Cleaning Studio

Transform, impute, deduplicate, and sanitize dirty tabular records using conversational commands with instant visual before/after diffs and one-click undo rollback.

Dual-Form Factor Deployment (Air-Gapped & Web)

Packaged as a standalone Inno Setup Windows installer (DataVerse_Setup_v1.0.exe) with embedded Python runtime and WebView2 desktop window, alongside our public Netlify + Render cloud PWA.
