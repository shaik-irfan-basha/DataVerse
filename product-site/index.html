The Challenge

Bridging the Gap Between Human Thought and Relational Data

Writing analytical queries should not require waiting on data engineering backlogs or risking database integrity.

Zero-Bypass Security Gatekeeper

Every query is strictly verified by SQLValidator AST checks and executed through a low-level SQLite C-authorizer callback that explicitly forbids write action codes.

Proactive Intent Clarification

Subjective or unquantified modifiers like "good products" or "best sales" trigger automated clarification options grounded strictly in existing schema columns with zero topic drift.

Self-Healing SQL Recovery

If an LLM introduces a dialect syntax pitfall or non-existent column, an iterative reflection pipeline feeds the error back into an automated repair loop before execution.

Conversational Data Cleaning

Detect duplicates, impute missing values (median/mean/mode), and inspect transformation previews before applying changes. Features a full linear undo and one-click revert stack.

Interactive Schema Visualizer

Automated foreign key inference visualizes multi-table schemas on a dark neon ER canvas. Use the visual JOIN builder to generate validated relational SQL directly into SQL Lab.

Adaptive Auto-Visualization

Automatically determines the quantitative topology of your results and renders bar charts, time-series lines, scatter plots, or proportional donut charts with a single click.

Seamless Workflow

How DataVerse Operates in 3 Steps

From raw files to verified intelligence in seconds.

1

Ingest Any Dataset

Drag and drop CSV, Excel (multi-sheet), JSON, or SQLite files. DataVerse profiles columns, detects delimiters, infers relational keys, and mounts an isolated in-memory database.

2

Ask in Natural Language

Type queries like "What are total sales by region?" or "Show products with above-average revenue". The Clarification Engine detects subjective terms and confirms your intent.

3

Verify, Visualize & Export

Inspect the generated SQL, explore interactive data tables with column sorting, view auto-rendered dark-neon charts, and export results directly to CSV, Excel, or JSON.
