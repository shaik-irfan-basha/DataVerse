Installing on Windows 10 or 11 (SmartScreen Notice)

Because DataVerse is an independent open-source project without a multi-thousand-dollar commercial EV code-signing certificate, Microsoft Defender SmartScreen may display a blue "Windows protected your PC" banner upon first execution. This is standard behavior for all newly released community executables.

Step 1: Open Installer

Double-click DataVerse_Setup_v1.0.exe after downloading.

Step 2: Click "More info"

On the blue SmartScreen popup, click the underlined link text.

Step 3: Click "Run anyway"

Confirm the installation. The setup wizard will launch immediately.

Step 4: Verify Checksum

Compare against the verified SHA-256 hash above for 100% peace of mind.

Developer Alternative: Run from Source

If you prefer running from Python source code or developing on Linux/macOS:

# Clone repository
git clone https://github.com/shaik-irfan-basha/DataVerse.git
cd DataVerse

# Install dependencies and start server
uv pip install -r requirements.txt
uvicorn backend.app:app --host 127.0.0.1 --port 8000
